# 角色卡链接导入

适用于 SillyTavern 1.18.0 及兼容版本的前端扩展。粘贴 PNG 角色卡图片直链，点击一次完成下载、角色数据校验、导入和角色列表刷新。无需额外服务器插件。

## 安装

在酒馆顶部打开「扩展程序」→「安装扩展程序」，粘贴以下仓库地址：

```text
https://github.com/Helloworld2345567/card-url-import-extentions-SillyTavern
```

安装完成后刷新页面，即可看到「角色卡链接导入」。通常选择安装给当前用户即可；管理员也可以选择全局安装，供本机酒馆的所有用户使用。

如果曾经手动安装到 `public/scripts/extensions/card-url-import`，请先将旧文件夹移到酒馆扩展目录以外保存备份，再安装本仓库，避免旧版和新版同时加载。

## 使用

1. 刷新酒馆页面，打开顶部「扩展程序」。
2. 展开「角色卡链接导入」。
3. 粘贴完整的 PNG 图片地址，点击「下载并导入」。
4. 出现「已导入」后，在角色列表中选择新角色。

Discord：点开图片 →「在浏览器中打开」→ 复制地址栏中的完整 URL。不要省略 `?ex=…&is=…&hm=…`。链接过期时，回到 Discord 重新复制。

也可粘贴 `media.discordapp.net/attachments/…/card.png?format=webp&quality=lossless` 这样的预览地址。扩展会转换为 `cdn.discordapp.com`，删除 Discord 的格式、质量和缩放参数，并保留签名及其他参数。

`discord.com/channels/…` 是消息页面，需要 Discord 登录才能获取附件；本扩展不读取 Discord 账号或会话，也不解析这种页面。`.webp` 文件不能通过改后缀恢复成角色卡。

## 支持范围

- PNG 格式的角色卡，包含 `chara` 或 `ccv3` 角色数据。
- HTTPS 图片直链。默认酒馆配置允许 Discord CDN、Catbox、GitHub Raw。
- 其他 PNG 直链由酒馆现有的 `whitelistImportDomains` 配置决定；扩展不会自动修改该配置。站点详情页、JSON、CHARX 不在此版本范围内。
- 请求由运行酒馆的电脑下载，无需浏览器跨域权限或额外服务器插件。该电脑必须能访问图片来源。
- 单张卡在扩展端限制为 32 MiB；下载等待最多 90 秒，可取消。酒馆内置下载接口会先在服务器缓冲文件，因此这不是服务器端下载大小或资源限制，取消浏览器等待也不保证中止服务器的上游请求。

校验通过后，扩展把原始 PNG 字节传给酒馆标准导入接口，不进行图片缩放或格式转换。酒馆仍按自己的标准导入逻辑保存角色数据。同名卡由酒馆生成新的文件名，已有角色不会被替换；重复导入会产生副本。

成功后保持当前聊天；不自动切换角色或发送聊天请求。完整来源 URL 仅用于本次请求，不保存到扩展设置；酒馆内置接口可能在服务器日志中记录请求 URL。

导入提交等待最多 120 秒。若网络中断或超时，服务器可能已保存角色卡；先刷新角色列表检查，避免重复导入。

## 更新、禁用与卸载

打开「扩展程序」→「管理扩展程序」，找到「角色卡链接导入」。可以在这里检查更新、拉取更新、启用或禁用，以及卸载。更新或禁用后按页面提示刷新酒馆。全局安装的更新和卸载需要酒馆管理员操作。

管理页从安装目录中的 Git `origin` 和当前分支检查更新，本仓库发布分支为 `main`。通过「安装扩展程序」安装会自动建立关联；仅复制文件或解压 ZIP 不会具备 Git 更新能力。保持安装目录没有手动源码修改，以便正常拉取更新。

也可由管理员在酒馆根目录手动克隆后刷新：

```sh
git clone https://github.com/Helloworld2345567/card-url-import-extentions-SillyTavern.git public/scripts/extensions/third-party/card-url-import-extentions-SillyTavern
```

卸载扩展不会删除已导入的角色卡或聊天记录。

## 验证

在本仓库根目录执行（Node.js 20+，无需安装 npm 依赖）：

```sh
npm test
```

测试覆盖 Discord 原图地址规范化、PNG 及元数据完整性、签名保留、字节不变、大小限制、登录及网络错误、服务端导入结果判定。测试使用合成角色卡和模拟网络，不写入真实角色或聊天数据。

测试会分别直接运行两个 Node 测试文件，无需启动酒馆。浏览器入口通过酒馆提供的模块及 `SillyTavern.getContext()` 工作。
